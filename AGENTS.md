## Workflow rules (apply every time)

1. **Edit only in `web/`.** Never edit `web-shareable/` directly — it's regenerated by the sync script and any local change there will be wiped.
2. **Test locally first.** Use `python3 app.py`, `./run.sh`, or `npm run dev` and verify on `http://localhost:3000`. Confirm the production build is green with `npm run build`.
3. **Ask before pushing.** Always confirm with the user before:
   - `git push` (any branch, especially `main`)
   - `vercel`, `vercel --prod`, `npx vercel`, `npx vercel --prod`
   This rule supersedes the general "ask once then proceed" pattern. Re-confirm every time, even if a previous push in the same session was authorised.
4. **Sync before sharing.** When the user wants to hand a clean copy to a reviewer, run:
   ```bash
   bash scripts/sync-shareable.sh
   ```

### Components

| Component | Role |
|---|---|
| `HeroSlideshow` | **Two device-specific layouts**, shared rotation/video state (data-driven via `slideshow[]` `{video:true, poster, title, type, location}`). **Desktop** = full-bleed cinematic video; **mobile** = video in a **16:9 band** (full frame, no portrait over-crop) + text below. A high-res **poster always paints first** (never black); only the active slide mounts a video (lazy) and it **fades in when it can play**. Autoplay muted/playsInline; **advances `HOLD_MS` (3s) after each video ENDS** (full-length playback, `onEnded` arms the hold and drops the fallback so no build animation cuts away abruptly; identical beat on all 4 slides) with a duration-synced CSS progress bar (`dur + HOLD_MS`) + a fallback timer. Duration is stored **with its slide** (`{i, ms}`) because `loadedmetadata` can beat React's first effect flush. **Play/pause toggle** (rightmost control) acts on the mounted video (gesture-safe, iOS Low-Power); optimistic icon flip. ←/→ keyboard. **Overlay**: project meta (type·location + name) is bottom-LEFT and small; ←/→ arrows sit at the left/right edges (vertically centred); dots+pause at the bottom; **no tagline / no slide counter**. Tags the section `data-hero` (navbar reads its height). |
| `SketchImage` | `mode="hover"` (default): shows a sketch by default, real photo on hover. If `sketchSrc` is passed → uses that provided sketch art (homepage category cards); otherwise an SVG `feConvolveMatrix` edge filter (fragile — looks faint on photos). `mode="static"` → just the photo, no sketch (used on **all sub-pages**). |
| `Navbar` | **Fully transparent bar** (no frosted box, no scroll-resize). Text/logo are **light over the homepage hero**, **dark elsewhere**; a page-coloured background **fades in (opacity layer) once scrolled past the hero** (and on inner pages) so content never overlaps the fixed bar — no animation glitch. Logo · wordmark · 4 nav items · Projects dropdown (own panel bg) · theme toggle · Get a Quote · mobile drawer. |
| `Footer` | Dark footer · logo (inverted) · Quick Links / Services / **Contact + "Follow" (social icon buttons)**. Social links/icons from `data/links.js`. **Pre-footer dark CTA is route-aware** (hidden on `/`). **Top gap removed on the homepage** so the dark CTA flows straight into the dark footer (gap kept on inner pages). Bottom bar: copyright + **"Developed by Nextgrow"** (→ nextgrow.in) — right on desktop, **centered + smaller on mobile**. |
| `Preloader` | Full-screen splash on first load · logo + progress. **Bulletproof**: safety timer armed BEFORE any storage access, `sessionStorage` in try/catch, no JS scroll-lock, + a **CSS-only failsafe** (`@keyframes preloader-failsafe`, ~3.6s) so it can NEVER trap users (in-app browsers / blocked storage / JS hang). ~2.2s on normal loads. |
| `SmoothScroll` | Lenis · skipped on touch / `prefers-reduced-motion` |
| `Cursor` | Lerped dot, event-delegated, hidden on touch |
| `Reveal` | IntersectionObserver fade-up + curtain mask reveals |
| `Stats` | Animated counters (17+, 500+, 06, 100%) on dark strip |
| `Services` | 6-tile grid with custom SVG line-art icons — **only on /about** now (removed from homepage) |
| `Testimonials` | 3 quote cards |
| `Marquee` | Looping headline strip — **removed from homepage** per client (component file kept but unused) |
| `Lightbox` | Click-to-zoom gallery with keyboard nav |
| `SectionHeader` | Consistent `[ NN ] Label` bar above sections |
